# Calendar Reminder App using Tkinter

A desktop application built with Python and Tkinter that allows users to view a calendar and create reminders for important dates and events.

# Features
1.View calendar by month and year
2.Add reminders with date and time
3.Display saved reminders in a list
4.Edit or delete reminders
5.Simple and user-friendly GUI

# Technologies Used
1.Tkinter
2.tkcalendar
3.JSON
