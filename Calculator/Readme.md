# Calculator App using Tkinter

A simple desktop calculator built with Python and Tkinter. This application provides basic arithmetic operations through a clean graphical user interface.

# Features
Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)
Clear button (C)
Responsive button-based GUI

# Technologies Used
Python 3
Tkinter (Python's built-in GUI library)
